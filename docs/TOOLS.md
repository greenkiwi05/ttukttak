# 도구 스펙

각 도구는 `apps/web/src/data/tools.js`의 slug와 1:1로 대응한다. 공통 요구사항은 `AGENTS.md` 참고.
"주 키워드"는 페이지 `title`·h1에, "보조 키워드"는 설명글과 FAQ에 자연스럽게 녹인다.

## 📅 날짜

### korean-age — 만 나이 계산기 ✅ 완료 (참고 구현)

### d-day — D-day 계산기
- 주 키워드: D-day 계산기 / 보조: 디데이 계산, 며칠 남았는지, 수능 디데이
- 입력: 목표일, 기준일(기본 오늘), "당일을 1일로 포함" 체크박스. 날짜 입력은 공용 `DateInput`
- 출력: D-N / D-Day / D+N, 남은 주·개월 환산
- 로직: `apps/web/src/lib/dday.js` — KST 기준 날짜 차이, 포함/미포함 옵션
- 테스트: 같은 날, 하루 전/후, 윤년 2월, 연말 연초 경계

### couple-anniversary — 커플 기념일 계산기
- 주 키워드: 커플 기념일 계산기 / 보조: 100일 계산, 1000일 계산, 사귄 날짜 계산
- 입력: 사귄 날(시작일), "시작일을 1일로" 체크(기본 체크, 한국 커플 관행)
- 출력: 오늘이 며칠째인지 + 기념일 표(100일 단위 ~3000일, 1~10주년), 지난 기념일은 흐리게, 다가오는 다음 기념일 강조
- 부가: 결과를 이미지로 저장/공유 버튼은 2단계(나중)로 미룸
- 테스트: 시작일 포함 여부에 따른 100일 날짜 차이(1일 차이)

### days-between — 날짜 사이 일수 계산
- 주 키워드: 날짜 계산기 / 보조: 두 날짜 사이 일수, 며칠 차이, 기간 계산
- 입력: 시작일, 종료일, 시작일 포함 여부
- 출력: 총 일수, ○주 ○일, ○개월 ○일, 평일 수(주말 제외, 공휴일은 제외하지 않는다고 명시)

## 🧮 생활 계산

### pyeong — 평수 계산기 (평 ↔ ㎡)
- 주 키워드: 평수 계산기 / 보조: 평 제곱미터 변환, 84㎡ 몇 평, 공급면적 전용면적
- 입력: 평 또는 ㎡ 중 하나 입력하면 다른 쪽 실시간 변환 (1평 = 400/121 ㎡ ≈ 3.305785㎡)
- 부가: 자주 찾는 면적 표(59㎡, 74㎡, 84㎡, 101㎡, 114㎡ → 평)
- 설명글: 전용면적과 공급면적 차이(개념만, 단지마다 다르다는 점 명시)

### percent — 퍼센트·할인율 계산기
- 주 키워드: 퍼센트 계산기 / 보조: 할인율 계산, 증감률 계산, 비율 계산
- 탭 4개: ① A의 B%는? ② A는 B의 몇 %? ③ A→B 증감률 ④ 정가·할인율 → 할인가(또는 정가·할인가 → 할인율)
- 소수 둘째 자리 반올림, 0으로 나누기 처리

### loan-repayment — 대출 원리금 상환 계산기
- 주 키워드: 대출 이자 계산기 / 보조: 원리금균등상환, 원금균등상환, 만기일시상환 계산
- 입력: 대출금, 연 금리(%, 사용자 입력), 기간(개월/년), 상환방식 3종, 거치기간(선택)
- 출력: 월 상환액(첫 달/마지막 달), 총 이자, 월별 상환표(접기/펼치기, CSV 다운로드)
- 원 단위 반올림 오차는 마지막 회차에서 보정
- 테스트: 금리 0% 케이스, 원리금균등 공식 검증

### savings-interest — 적금·예금 이자 계산기
- 주 키워드: 적금 이자 계산기 / 보조: 예금 이자 계산, 월복리, 세후 이자
- 입력: 예금/적금 선택, 금액(월 납입액), 기간(개월), 연 금리, 단리/월복리, 과세 옵션(일반과세 15.4% / 비과세 / 세금우대 9.5%)
  - 세율은 **사용자 입력**(%) 칸으로 둔다. 15.4%·0%·9.5% 버튼은 입력칸을 채워 주는 편의 기능일 뿐, 로직(`apps/web/src/lib/savings.js`)은 세율을 인자로만 받는다 (AGENTS.md 원칙 2)
  - 페이지에 "세율은 바뀔 수 있으니 가입 상품·금융기관 안내를 확인하세요" 문구 표시
- 출력: 원금 합계, 세전 이자, 세금, 세후 수령액

## 📁 파일 변환 (모두 브라우저 내 처리, 업로드 없음 문구 필수)

### heic-to-jpg — HEIC JPG 변환
- 주 키워드: HEIC JPG 변환 / 보조: 아이폰 사진 jpg 변환, heic 파일 열기
- 라이브러리: `heic2any` (동적 `import()`)
- 기능: 여러 장 드래그&드롭, 품질 슬라이더(기본 0.9), 개별 다운로드 + 전체 ZIP(`fflate`)
- 제한: 장당 50MB, 최대 30장. 진행률 표시. 실패한 파일은 사유 표시

### image-compress — 이미지 용량 줄이기 (MB 지정)
- 주 키워드: 이미지 용량 줄이기 / 보조: 사진 용량 줄이기, 2MB 이하로, 300KB 이하
- 차별점: **목표 용량 입력**(빠른 선택 버튼: 100KB, 300KB, 500KB, 1MB, 2MB) → 품질 이진 탐색, 그래도 크면 해상도 단계적 축소
- 구현: `<canvas>` + `toBlob('image/jpeg', q)`, 품질 탐색은 `apps/web/src/lib/compress.js`에 순수 로직(탐색 알고리즘)으로 분리해 테스트
- 출력: 원본 vs 결과 용량·해상도 비교, 미리보기

### pdf-merge-split — PDF 합치기·나누기
- 주 키워드: PDF 합치기 / 보조: PDF 나누기, PDF 페이지 추출, PDF 순서 바꾸기
- 라이브러리: `pdf-lib` (동적 import)
- 탭: 합치기(파일 순서 드래그), 나누기(페이지 범위 "1-3, 5" 입력 파서 → `apps/web/src/lib/pageRange.js` 테스트)

### hwp-to-pdf — HWP PDF 변환 ✅ (뷰어 + 화면 캡처 PDF)
- 주 키워드: HWP PDF 변환 / 보조: 한글 파일 열기 맥, hwp 뷰어 온라인
- 엔진: `@ohah/hwpjs` 0.1.1 (버전 고정, WASM 약 7MB + worker를 `?url`로 이 페이지에서만 로드)
- 보기: `createCanvasSurface` 읽기 전용. 배포용 문서(`content.primarySource === 'distribution_viewtext'`)는 쪽 모양을 못 그려서 열지 않고 안내
- PDF: `toHtml`은 진단용 문구가 섞인 의미 구조 HTML이라 쓰지 않는다. 대신 뷰어 캔버스를 쪽마다 캡처 → pdf-lib (쪽 경계는 배경색 틈으로 찾음, `src/lib/pageScan.js`). 글자는 이미지라 검색·복사 불가를 안내
- 상세 조사: `docs/spikes/hwp.md`

## 📷 사진

### id-photo — 증명사진 규격 맞추기
- 주 키워드: 증명사진 사이즈 / 보조: 여권사진 규격, 반명함 사이즈, 이력서 사진 크기
- 규격 프리셋: 반명함·이력서 3×4cm(354×472px), 여권 3.5×4.5cm, 명함판 5×7cm, 직접 입력(cm). 모두 300dpi
- 기능: 업로드 → 비율 고정 크롭 박스(드래그·확대) → 지정 픽셀/300dpi로 출력 → JPG 다운로드
- 배경 제거·흰색 처리는 2단계(나중). 1단계는 크롭·리사이즈만.
- 설명글: 여권사진 세부 규정은 외교부 안내를 따르라고 링크(규정 자체를 복제하지 않음)

## 💌 문구 생성

### greeting-message — 경조사 문구 생성기
- 주 키워드: 경조사 문구 / 보조: 축의금 봉투 문구, 조의금 문구, 조문 감사 문자, 승진 축하 문구, 명절 인사 문구
- 방식: **미리 작성한 문구 템플릿을 조합**한다. AI·외부 API 호출 없음 (AGENTS.md 원칙 1)
- 입력: 상황(결혼·출산·돌·생일·승진·개업·조의·조문 감사 답례·명절·연말연시·감사), 관계(직장 상사·동료·친구·가족·거래처), 말투(격식/친근), 받는 사람 이름(선택)
- 출력: 문구 후보 여러 개 + 복사 버튼, 봉투 앞면 짧은 문구(예: 祝結婚, 謹弔)는 별도 표시
- 로직: `apps/web/src/lib/greeting.js` — 템플릿 데이터 + `{이름}` 치환 + 조건 필터링 순수 함수
- 테스트: 모든 상황×관계×말투 조합에서 후보가 1개 이상 나오는지, 이름 미입력 시 자리표시자가 남지 않는지
- 설명글: 상황별 예절(봉투 쓰는 법 등)은 널리 알려진 관행만, 단정하지 않는 표현으로

## 4단계 추가 도구 (모두 브라우저 처리, 외부 API 없음)

### char-count — 글자수 세기 (✍️ 글자·문구)
- 주 키워드: 글자수 세기 / 보조: 자소서 글자수, 공백 제외 글자수, 바이트 계산
- 출력: 공백 포함·제외 글자수, 바이트(UTF-8 / 한글 2바이트 기준), 단어·줄·문단 수, 원고지 매수(200자 단순 계산), 목표 글자수 진행 막대
- 글자는 화면에 보이는 단위(grapheme)로 센다 (이모지 1자). 계산 규칙을 페이지에 명시 (사이트마다 기준이 다름)
- 로직: `src/lib/charCount.js`

### qr-code — QR코드 만들기 (✍️ 글자·문구)
- 주 키워드: QR코드 만들기 / 보조: QR코드 생성, 와이파이 QR코드, 링크 QR
- 종류: 링크, 텍스트, 와이파이, 전화, 문자, 이메일, 연락처(MECARD). 색·크기·오류 복원 수준, PNG·SVG 저장
- 라이브러리: `qrcode-generator` (동적 import). 문자열 조립·이스케이프는 `src/lib/qr.js`에서 테스트

### jpg-to-pdf — JPG PDF 변환 (📁 파일 변환)
- 주 키워드: JPG PDF 변환 / 보조: 사진 PDF 만들기, 이미지 PDF 변환, 여러 사진 PDF 하나로
- 기능: 여러 장 순서 정렬, 용지(A4·사진 크기 그대로), 방향(자동·세로·가로), 여백. `pdf-lib` 동적 import
- 사진 회전 정보를 반영하려고 canvas로 한 번 그려서 넣는다. 배치 계산은 `src/lib/pdfLayout.js`

### image-convert — 이미지 변환·크기 조절 (📁 파일 변환)
- 주 키워드: 이미지 크기 조절 / 보조: PNG JPG 변환, WEBP 변환, 사진 픽셀 줄이기
- 기능: 형식(JPG·PNG·WEBP), 크기(비율 % / 가로 / 세로 / 가로×세로 박스 안에 맞춤), 품질. 여러 장 + ZIP
- 크기 계산: `src/lib/resize.js`

### exif-remove — 사진 위치정보 지우기 (📷 사진)
- 주 키워드: 사진 위치정보 삭제 / 보조: EXIF 삭제, 사진 GPS 지우기, 메타데이터 제거
- JPEG: 다시 압축하지 않고 바이트에서 EXIF·XMP·IPTC·주석 구간만 잘라낸다 (화질 손실 없음). 색 프로필(ICC)·Adobe 구간은 유지, 회전 정보는 최소 EXIF로 다시 넣는다
- PNG: eXIf·tEXt·iTXt·zTXt 청크 제거
- 지우기 전에 GPS 좌표·촬영 기기·촬영 시각을 보여 준다. 로직: `src/lib/exif.js`

### lunar-calendar — 음력 양력 변환 (📅 날짜)
- 주 키워드: 음력 양력 변환 / 보조: 음력 생일 계산, 음력 달력, 올해 음력 생일
- 라이브러리: `korean-lunar-calendar` (한국천문연구원 기준 데이터 내장, 오프라인). 지원 범위 밖은 안내
- 음력 생일 → 앞으로 10년 양력 날짜 표. 윤달 생일은 평달로, 그해에 30일이 없으면 29일로 계산하고 표시
- 로직: `src/lib/lunar.js`

### ladder — 사다리타기 (🎲 뽑기·게임)
- 주 키워드: 사다리타기 / 보조: 사다리 게임, 온라인 사다리, 사다리 타기 랜덤
- 2~12명, 결과 입력(당첨·꽝 등), SVG로 경로 애니메이션. 난수는 `crypto.getRandomValues`
- 생성·추적 로직: `src/lib/ladder.js` (가로줄이 붙어 나오지 않음, 결과는 항상 1:1)

### random-pick — 제비뽑기·랜덤 뽑기 (🎲 뽑기·게임)
- 주 키워드: 제비뽑기 / 보조: 랜덤 뽑기, 당첨자 추첨, 팀 나누기, 순서 정하기
- 모드: 당첨자 N명 뽑기, 팀 N개로 나누기, 전체 순서 정하기. 로직: `src/lib/randomPick.js`

### travel-payment — 해외 결제 수수료 계산기 (🧮 생활 계산)
- 주 키워드: 해외 결제 수수료 계산기 / 보조: 해외 카드 수수료, 루피아 환율 계산, 원화결제 DCC
- 입력: 통화(IDR·USD·JPY 등, 100단위 표시 통화 구분), 현지 가격, 환율(사용자 입력, 통화별로 localStorage에 기억), 세금·봉사료 %, 브랜드·해외이용 수수료 %, DCC 추가 % (모두 사용자 입력, 버튼은 입력 편의)
- 출력: 카드 예상 청구액과 내역, 원화결제 시 추가 금액, 자주 쓰는 금액 → 원화 표
- 실시간 환율 API는 쓰지 않는다 (원칙 1). 로직: `src/lib/travelPay.js`

## 5단계 추가 도구

### dutch-pay — 더치페이 계산기 (🧮 생활 계산)

### video-compress — 동영상 용량 줄이기 (📁 파일 변환)
